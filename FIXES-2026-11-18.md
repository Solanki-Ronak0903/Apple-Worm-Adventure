# Admin Level Management Test Fixes — 18 November 2026

This patch addresses the two failures reported after installing the Level Management update.

## 1. Admin level library assertion

- Changed the heading to keep `Level library` as a continuous text node while retaining the visual period.
- Updated `AdminLevelManagementTest` to verify the first page separately.
- Added a dedicated `world=cloud` filter request to verify the Sky Temple levels, which are not part of the first 15-row page.

## 2. Initial release / future level publication

- The one-time migration `2026_11_02_000001_limit_initial_release_to_25_levels.php` hides future levels that existed before the initial 25-level launch.
- `DatabaseSeeder` intentionally does not change publication choices for existing records, because later publication is controlled by administrators.
- Updated `InitialReleaseLevelsTest` to exercise these responsibilities separately: invoke the initial-release migration against a pre-existing published Level 26, seed the 25 launch levels, verify Level 26 is hidden, then simulate an administrator publishing it and verify a subsequent seed preserves that choice.

## Scope

No gameplay mechanics, level maps, wallet balances, reward logic, player progress, routes, or seeder behavior were changed.

## Local verification

- PHP lint completed for all PHP files under `app`, `database`, `routes`, and `tests`.
- Full PHPUnit execution was not available in this packaging environment because the ZIP does not contain `vendor/` and Composer/PHPUnit executables are unavailable here. Run `php artisan test` on the Windows development machine after extracting this update.
