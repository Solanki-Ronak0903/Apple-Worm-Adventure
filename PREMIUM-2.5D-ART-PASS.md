# Art direction note

The earlier continuous 2.5D run-and-jump platformer exploration has been discontinued. The approved gameplay is an original side-view tile puzzle.

The current Canvas presentation uses themed terrain palettes, grass/stone tile faces, wooden push crates, animated fruit, spikes, a portal, a segmented expressive worm, drifting scenery and movement/collection effects. The puzzle rules remain grid-stepped and server-authoritative; visual animation must not turn the game into a reflex platformer.
